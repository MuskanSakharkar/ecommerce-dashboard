# 📊 E-commerce Analytics Dashboard

## 🔍 Overview
An interactive data analytics dashboard built using Streamlit to analyze e-commerce sales performance.  
It enables users to explore trends, monitor profitability, and identify key business insights through dynamic visualizations.



## 🚀 Features
- Multi-level filtering (Region, State, Category, Date)
- Monthly sales trend analysis
- Top-performing and loss-making products
- City and state-wise sales insights
- Interactive KPIs (Sales, Profit, Quantity)
- Download filtered dataset



## 🛠️ Tech Stack
- Python
- Pandas
- Streamlit



## ▶️ How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py



## 📁 Dataset
Superstore dataset (Kaggle)



## 🎯 Key Insights Generated
- Identifies most profitable categories and regions  
- Highlights loss-making products for business improvement  
- Tracks sales trends over time for better decision-making
