# E-commerce Analytics Dashboard

![Dashboard Overview](https://raw.githubusercontent.com/MuskanSakharkar/ecommerce-dashboard/main/assets/dashboard-overview.png)

## Overview
This project is an interactive e-commerce analytics dashboard built using Streamlit.  
It enables users to analyze sales performance, monitor profitability, and extract actionable business insights through dynamic visualizations and filters.

The dashboard is designed to simulate a real-world business intelligence solution used in e-commerce and retail analytics.

## Features
- Multi-level filtering (Region, State, Category, Date)
- Monthly sales trend analysis
- Sales vs Profit comparison
- Top-performing products analysis
- Identification of loss-making products
- City and state-level sales insights
- Interactive KPI metrics (Total Sales, Profit, Quantity)
- Product search functionality
- Download filtered dataset

## Installation & Usage

1. Clone the repository:
```
git clone https://github.com/MuskanSakharkar/ecommerce-dashboard.git
cd ecommerce-dashboard
```

2. Install dependencies:
```
pip install -r requirements.txt
```

3. Run the application:
```
streamlit run app.py
```

---

## Dataset
This project uses the Superstore dataset available on Kaggle.  
The dataset contains information related to orders, sales, profit, customers, regions, and product categories.

---

## Key Insights
- Identifies the most profitable and least profitable categories  
- Highlights loss-making products for business optimization  
- Analyzes regional and state-wise sales performance  
- Tracks monthly sales trends to support decision-making  

---

## Project Objective
The objective of this project is to demonstrate how raw business data can be transformed into actionable insights using data analytics and visualization techniques.

This dashboard provides an intuitive interface for exploring data and supports better decision-making through interactive analysis.
